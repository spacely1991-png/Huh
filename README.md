# GTA V Story Mode Companion

Static offline-capable web app. Upload **the files inside this folder** to the repository root. In repository Settings → Pages, select Deploy from a branch → main → /(root), then Save. Open https://spacely1991-png.github.io/GTA-/ in Safari while online, check it works, Share → Add to Home Screen. Reopen once while online before testing in Airplane Mode. Each browser/device stores progress separately; export notes as a backup.
